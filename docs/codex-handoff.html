Ductor / Codex

Phone and desktop handoff

Continue Codex from Telegram, then pick that same session back up in the local interactive Codex CLI. This is session-id handoff, not a shared live terminal.

What It Solves

Ductor runs Codex through codex exec, so sessions created or continued from Telegram can be hidden from plain codex resume. The handoff feature gives you the exact desktop command with the right flags and project directory.

Phone To Desktop

  1. Open Telegram and send /sessions.
  2. Tap Resume On Desktop for the attached Codex session.
  3. Run the shown command in your desktop terminal.
codex resume --include-non-interactive --all --cd /path/to/project <session_id>

Desktop Helper

List ductor-known Codex sessions:

ductor codex resume

Resume a named attached session:

ductor codex resume @pm99

Useful Commands

ductor codex resume --main
ductor codex resume --last-phone
ductor codex resume --print @pm99
ductor codex resume --help

Use --print when you want to see the raw Codex command without launching the TUI.

Desktop To Phone

  1. Open Telegram and send /sessions.
  2. Tap Browse Codex.
  3. Pick the project and session.
  4. Use Use In This Chat for the main chat, or Attach As Named for a named target.

Limits By Design

  • This does not attach Telegram to an already-open desktop TUI process.
  • A fresh Telegram session needs one completed Codex turn before it has a desktop-resumable session id.
  • Named sessions resume with ductor codex resume @name.
